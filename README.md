# 安徽大学物理与光电工程学院本科相关资料

这里是安徽大学物理与光电工程学院本科相关资料的Github网页，各种资料通过多种渠道进行收集，按照课程进行了分类，希望有所帮助。

若发现库中相关问题，欢迎在此提交issue反馈。

感谢所有上传资料无私分享的用户！感谢您的使用。

## 以下几点可以注意：

1、资料为无私分享，仅供下载自用，请不要广泛外传。

2、这里仅列举了教师分发到学生本地的资料。其他课程，例如王敏老师的《模拟电子技术》，可以通过老师常用的网站（在此处例为学习通和雨课堂）学习。

3、认真听课、学习课程并练习，在考试层面肯定是可以通过的。

4、光电专业课程多且复杂，有时间的前提下不推荐速通（当然没时间另说）。

5、期末考试的出题风格是有规律的，抓住考试技巧，能降低通过考试的难度。

6、实在没招了可以通过网课和AI辅助学习。

7、要学会善用AI，批判性看待AI的回答，请一定不要完全依赖于AI。
